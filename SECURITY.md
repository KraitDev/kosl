# Security Policy

## Supported Versions
We actively maintain and provide security patches for the latest release version of KOSL.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability
We take the security of our parsing engine seriously. If you discover a vulnerability (such as a parser panic exploit, buffer overflow vulnerability, or memory-leak vector):

1. **Do not** open a public GitHub issue.
2. Report privately via Private Vulnerability Reporting in Github.
3. Provide detailed steps or a specific crash-inducing `.kosl` payload file to help reproduce the vulnerability.

We will acknowledge your report within 48 hours and provide an estimated timeline for a patch. Once a security patch is merged and released, credit will be given to the security researcher.
